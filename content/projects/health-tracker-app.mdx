## Project Overview
The Health Tracker App is a comprehensive solution for monitoring personal health and fitness goals. Built with modern software engineering practices, the application provides users with tools to track their vital statistics, set health goals, and maintain a consistent fitness routine. It also has additional functionality to allow medical practioners monitoring access, to properly monitor their patients' progress and current health.
